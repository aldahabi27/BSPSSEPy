## 3BUS folder
Contains a 3 bus example system for BSPSSEPy Application.

## IEEE9 folder
Contains the IEEE9 Bus system. Previously used to contain ~20 Versions.
Currently, two versions are kept.

1. Ver1 does not contain IBR.
2. Ver2 contains IBR.

## SampleCase folder
Contains a general Config and Conv file that can be used to setup a new case
file. Just copy these files and modify the content to suit your case file setup/configuration.
