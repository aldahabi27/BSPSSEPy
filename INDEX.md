## case folder
Contains the simulation case files (PSSE files, BSPSSEPy Configuration files
and Simulation outputs)

## doc folder
Contains support files for `manual.md` (tutorial images, case files and excel
configuration sheets + sample plans)

## fun folder
Contains all BSPSSEPy Application functions.

## MATLAB Folder
Contains MATLAB related code files which can be used to plot BSPSSEPy output.
